### Features
* **Length Check:** Ensures the password is at least 8 characters long.
* **Common Word Filter:** Flags easily guessable words or patterns (like "123" or "password").
* **Character Variety:** Verifies that the password contains a healthy mix of:
  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Special symbols
